# Changelog

## 0.1.0 (2026-09-20)

Initial release.

### Features
- All traffic routed through Tor SOCKS5 proxy
- WebRTC disabled, Client Hints stripped, all permissions denied
- **Phantom Mode** — custom User-Agent: `Ghoster/0.1.0` on `PhantomOS 1.0`
- **Stealth Mode** — blend in as Firefox/Windows (Tor Browser fingerprint)
- **memento** — built-in search engine, proxies Google through Tor, stores nothing
- **Nationality picker** — 25 countries with geolocation, timezone, and language spoofing
- **New Identity** — wipes cookies, cache, storage, DNS cache, auth in one click
- SHA-256 session integrity hash
- Dark theme, frameless window, minimal UI
- Builds for macOS (DMG, ZIP), Windows (NSIS, portable), Linux (AppImage, deb, tar.gz)
